# Bubble Level Forge: AI-инструмент генерации уровней

Тестовое задание: веб-инструмент для игры Bubble Associations: Word Game
(пазл «разложи пузыри со словами по категориям»). Инструмент генерирует уровни
с помощью AI, проверяет их решаемость, оценивает сложность и экспортирует JSON.

Этот файл подгружается автоматически. Подробные правила: `rules.md`,
инструкции для AI-агентов: `AGENTS.md`, текущее состояние: `status.md`.

## Структура проекта

- `site/` - сайт-отчёт о выполнении задания (деплой на serge-mel.surge.sh)
- `tool/` - сам веб-инструмент (появится по ходу работы)
- `levels/` - сгенерированные уровни в JSON (сдаём 10 штук с оценками)
- `reference/` - видео и скриншоты целевой игры (в git не попадает)

## Ключевые договорённости

- История изменений ведётся через git: каждый смысловой шаг = коммит с понятным сообщением.
- Секретный ключ AI-провайдера не хранится ни в статических файлах, ни в репозитории:
  страница ходит к AI через серверный прокси, ключ живёт только в настройках хостинга прокси.
- Сайт-отчёт деплоится командой: `npx surge ./site serge-mel.surge.sh`
- «Готово/verified» говорим только после проверки в реальном браузере.
