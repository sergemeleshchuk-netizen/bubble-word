# Схема уровня JSON

Зафиксирована 30.07.2026 (Шаг 2). Источник параметров: `reference-analysis.md`
(категория всегда = 4 слова, имена скрыты до сборки, лимит только по ходам,
поле ~20-24 пузыря с досыпкой). Подход и кривая: `approach.md`.

```json
{
  "level_id": 1,
  "difficulty_target": 2,
  "categories": [
    { "id": "fruits", "name": "Fruits", "words": ["apple", "mango", "peach", "plum"] }
  ],
  "traps": [ { "word": "orange", "home": "fruits", "tempts": "colors" } ],
  "repeats": [ { "word": "milk", "prev_level": 2, "prev_category": "drinks" } ],
  "board": { "start_bubbles": 22, "move_limit": 34, "move_limit_k": 1.4 },
  "extensions": { "chunks": [], "chains": null, "picture_words": [] }
}
```

## Поля

- `level_id` - номер уровня в пакете (int, с 1).
- `difficulty_target` - целевая сложность 1-10, которую закладывал генератор.
  Фактическую оценку даёт отдельный шаг (скилл оценки сложности).
- `categories` - список категорий уровня. Каждая:
  - `id` - id категории в базе `tool/data/categories.json` (трассируемость;
    для категории вне базы - kebab-case новый id);
  - `name` - имя, которое игра покажет на финальном оранжевом пузыре;
  - `words` - **ровно 4 слова**, lowercase, каждое встречается на уровне один раз.
- `traps` - слова-ловушки: `word` лежит в пуле обеих категорий базы, но на
  уровне у него ровно один дом. `home`/`tempts` - id категорий уровня
  (обе обязаны присутствовать в `categories`). Ловушка валидна, если слепой
  решатель всё равно кладёт слово в `home`.
- `repeats` - игра с памятью игрока: слово уже встречалось в прошлом уровне
  пакета в ДРУГОЙ категории. `prev_level`/`prev_category` - где было.
- `board`:
  - `start_bubbles` - пузырей на поле на старте и цель досыпки (референс: 20-24);
  - `move_limit` - лимит ходов; `null` = без лимита (туториальный L1);
  - `move_limit_k` - коэффициент K из формулы `move_limit = ceil(3 * M * K)`,
    M = число категорий; K: 1.8 туториал, ~1.5 просторно, ~1.35 обычный,
    1.25 спайк (снято с уровней 2-19 референса).
- `extensions` - расширения референса, генератор v1 их НЕ заполняет:
  `chunks` (слова из кусочков, с L10), `chains` (цепи, с L20),
  `picture_words` (пузыри-картинки, с L4).

## Инварианты (проверяются валидатором и глазами)

1. В каждой категории ровно 4 слова; слово на уровне уникально
   (двусмысленность делаем ловушками, не дублями).
2. Каждый trap.word входит в words своей home-категории; tempts-категория
   есть на уровне, и trap.word НЕ входит в её words.
3. `move_limit >= 3 * M` (минимум ходов: 3 мерджа на категорию), иначе
   уровень непроходим.
4. `start_bubbles <= 4 * M` и в диапазоне 20-24 (кроме маленьких уровней,
   где слов меньше: тогда все слова на поле).
5. Слов из блок-листа (`tool/data/blocklist.txt`) нет.

## Эталонные уровни (собраны руками, Шаг 2)

- `etalon/e1.json` - сложность 1: 5 далёких категорий, без ловушек, K=1.8.
- `etalon/e2.json` - сложность 5: 8 категорий, ловушки orange (fruits↔colors)
  и bark (tree-parts↔dog-things), K=1.4.
- `etalon/e3.json` - сложность 9 (спайк): смежные пары fruits↔berries и
  sweets↔baked-goods, 4 ловушки (cherry, cookie, cold, diamond),
  повтор milk (E2 drinks → E3 dairy), K=1.25.
