# Оценка уровня: сложность и фан

Источник правды для скилла `level-evaluator` (шаг 5 approach.md).
Файл живой: улучшаем итеративно. Каждое изменение модели = коммит +
повторный прогон эталонов (калибровка внизу). Черновик факторов сложности
из `rules.md` развёрнут здесь в считаемую модель.

Уровень получает две оценки по 10-балльной шкале с шагом 0.5:

- **D (difficulty)** - насколько уровень тяжело разложить;
- **F (fun)** - насколько уровень интересно разложить.

Ключевой принцип: **фан не равен лёгкости**. Пик фана - управляемая
двусмысленность: ловушки, которые заставляют усомниться, но разрешаются
честно («ага!»). Неуправляемая двусмысленность (слово, спорное вне замысла)
убивает и фан, и честность.

## Вход оценки

1. JSON уровня (`levels/SCHEMA.md`).
2. Результаты слепого решателя (`levels/solver/<имя>.solution.json` + report):
   без прогона решателя оценка не выставляется - эмпирика решателя
   (сомнения, уверенность) входит в обе шкалы.
3. База слов `tool/data/categories.json` (zipf, `related`, пересечения).

Структурные метрики считает `tool/scripts/eval_metrics.py` (детерминированно),
семантические суждения (узнаваемость, сферы, смежность сверх базы) даёт
оценщик по якорям ниже.

## Сложность D

`D = clamp(1 + F1 + F2 + F3 + F4 + F5 + F6 + F7, 1, 10)`, округление до 0.5.

| Фактор | Что измеряет | Баллы |
|---|---|---|
| F1 масштаб | категорий M | M<=6: 0; 7-8: +1; 9-10: +1.5; 11+: +2.5 |
| F2 ловушки | валидные ловушки (решатель положил в home) | +1 за каждую, максимум +3 |
| F3 близость | смежные пары категорий; разрезание одной темы на две | +0.75 за пару (максимум +1.5); +1 за разрезание |
| F4 редкость | слова с zipf < 3.0 (экзотика уровня AGLET; бытовые donut/hamster живут в 3.0-3.5 и редкостью не считаются) | +0.5 за слово, максимум +1 |
| F5 лимит | K из board | K>=1.6: 0; 1.35<=K<1.6: +0.5; K<1.35: +1 |
| F6 память | repeats (слово из прошлого уровня в новой категории) | +0.5 за повтор, максимум +1 |
| F7 внеплановая двусмысленность | сомнения решателя ВНЕ заявленных ловушек; низкая уверенность | +0.25 за сомнение (максимум +0.5); +0.5 если есть категория с уверенностью <=3; итог максимум +1 |

Примечания:
- Округление D и F: до ближайшего 0.5, ровно .25 округляем вверх.
- Смежность (F3) считаем по эмпирике, а не по формальной связи: пара идёт
  в зачёт, если категории тематически родственны И решатель реально спутывался
  на их границе (сомнение или расхождение) ЛИБО это заявленное разрезание темы.
  Кандидатов подсказывает `related` базы, но связь через одно слово-ловушку
  (Fruits-Colors из-за orange) смежностью НЕ является - это уже посчитано в F2.
- F7 не двойной счёт ловушек: сомнение по заявленной ловушке идёт в F2/фан,
  сюда только незапланированное.

## Фан F

База 5, дальше якоря; итог clamp 1-10, округление до 0.5.

| Якорь | Баллы |
|---|---|
| Узнаваемость: все категории конкретные, бытовые, угадываются по 4 словам | +1 |
| Абстрактная / натужная категория | -1 за каждую, максимум -2 |
| «Ага-момент»: ловушка валидна И решатель отметил сомнение (укусила, но честно) | +0.5 за каждую, максимум +2 |
| Разнообразие: категории из разных сфер жизни | +0.5 |
| Тематический сюжет уровня (как «путешествие» в journey-d7) | +0.5 |
| Больше половины категорий из одной сферы БЕЗ замысла смежности | -1 |
| Незапланированное сомнение решателя (спорность вне замысла) | -0.25 за каждое, максимум -1 |
| Темп: есть «стартовая» категория (уверенность 5, без сомнений) - быстрый первый успех | +0.5 |
| Не туториал (D>=4), но ни одного ага-момента - пресно | -0.5 |

Порог честности: **solver FAIL = уровень бракован**, F не выше 3,
оценка сложности не выставляется (сначала чинить генератором).

## Выход оценки

`levels/eval/<имя>.eval.json` (числа + разбивка по факторам) и
`levels/eval/<имя>.eval.md` (объяснение каждого фактора словами:
задание требует «числовая оценка + из чего складывается»).

## Калибровка (эталоны)

Модель обязана попадать в целевую сложность эталонов с допуском +-1.
После любого изменения этого файла - повторный прогон всех строк таблицы.

| Уровень | Цель D | Модель D | F | Прогон |
|---|---|---|---|---|
| etalon/e1 | 1 | 1.0 | 7.0 | 30.07 |
| etalon/e2 | 5 | 5.0 | 8.0 | 30.07 |
| etalon/e3 | 9 | 8.5 | 9.0 | 30.07 (ред.3 после двух FAIL решателя) |
| demo/journey-d7 | 7 | 7.5 | 7.5 | 30.07 |

Если новый уровень оценивается «странно» (число не бьётся с ощущением от
playable) - это сигнал улучшать ЭТОТ файл, а не подгонять отчёт.
