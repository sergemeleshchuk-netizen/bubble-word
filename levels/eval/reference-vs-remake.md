# Планка: запись оригинала против нашего ремейка

Замер от 03.08 (пересчитан после пересборки базы: прежние числа снимались со
снимка, в котором не хватало пятнадцати правил из патча по записи, и потому
занижали обе двадцатки). Обе прогнаны одной командой, одной моделью, по одной
базе — иначе сравнивать нечего:

```bash
cd tool/word_content_pipeline
.venv/bin/word-content eval-levels --db database/content.sqlite --prefix REF \
    --output ../../levels/eval/REF-pack.eval.json
.venv/bin/word-content eval-levels --db database/content.sqlite --prefix RMK \
    --output ../../levels/eval/RMK-pack.eval.json
```

`REF001..REF020` — двадцать уровней записи оригинала, разобранные покадрово.
`RMK001..RMK020` — наш ремейк той же двадцатки, собранный своей базой.
Модель оценки — `levels/EVAL.md`, детерминированный вариант (раздел
«Пакетная оценка» там же).

## Три конкретные болезни ремейка

**1. Надписи-признаки вместо тем.** 43 группы из 192 названы так, что игрок их
не угадывает, а добирает по остатку: PLUMBING WORDS, ASTRONOMY WORDS, PARTY
THINGS, HAMMERED THINGS, PAINFUL THINGS, LIGHT THINGS, HAIR WORDS, READING
WORDS. В записи такая надпись ровно одна на двадцать уровней (GEOGRAPHICAL
OBJECTS). У оригинала темы называются словом: FRUITS, PETS, CAT, COFFEE,
DOCTOR, BREAD, CHESS.

**2. Пузырь, который не пузырь.** 72 токена из 768 — многословные или длиннее
двенадцати символов: «science center», «soap making», «candle making», «rash
guard», «picture day». В записи таких 11. Уровень 5 наглядно:

| | оригинал REF005 | ремейк RMK005 |
|---|---|---|
| группы | PETS, CAT, BAKING, BEVERAGES, COFFEE, FLOWERS, INSECTS, DAIRY, POLYGONS, NUTS, ILLNESS | EXTINCT ANIMALS, CRAFTS, BONES, HAIR WORDS, JOB HUNTING, READING WORDS, CLEANING SUPPLIES, MONTHS, SNACK NUTS, BEEKEEPER, CANDLE MAKING |
| слова | dog, fish, bird, cat / meow, purr, whiskers, scratch / cake, pie, cookie, bread | bones, dinosaur, mammoth, raptor / soap making, candle making, pottery, sewing / chapter, index, appendix, excerpt |
| D / F | 10.0 / 8.0 | 6.5 / 4.0 |

**3. Пять ага-моментов на двадцать уровней против двадцати четырёх.**
Генератор пересечения почти не ставит, а отбраковывает: слово, которое тянет в
соседнюю группу, отсеивается до сборки. Пять штук (RMK004, 011, 018, 019)
пришли из механики спроектированной ловушки — она уже есть, но срабатывает
редко. Оригинал на пересечениях держится — `orange` фрукт рядом с овощами,
`carrot` овощ оранжевого цвета, `cold` болезнь рядом с температурой, `bark`
собачий лай рядом с деревьями. По шкале это +1 к D и +0.5 к F за каждую, и
уровень сложнее туториала без единого ага-момента получает −0.5.

## Что это значит для задачи

Цель — двадцать уровней с F выше 7.03 и D не ниже 6.42. Порядок работ следует
прямо из таблицы вкладов: сначала надписи и узнаваемость тем (−1.45 и −0.50
лежат там), потом ловушки (−0.45 плюс снятие −0.10 «пресно»), и только потом
всё остальное. Первые два пункта — отбор контента, третий — настройка уже
написанной механики спроектированной ловушки.
