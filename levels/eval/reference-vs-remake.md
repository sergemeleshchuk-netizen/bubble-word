# Планка: запись оригинала против нашего ремейка

Замер от 01.08. Обе двадцатки прогнаны одной командой, одной моделью, по одной
базе — иначе сравнивать нечего:

```bash
cd tool/word_content_pipeline
.venv/bin/word-content eval-levels --db database/content.sqlite --prefix REF \
    --output ../../levels/eval/REF-pack.eval.json
.venv/bin/word-content eval-levels --db database/content.sqlite --prefix RMK \
    --output ../../levels/eval/RMK-pack.eval.json
```

`REF001..REF020` — двадцать уровней записи оригинала, разобранные покадрово.
`RMK001..RMK020` — наш ремейк той же двадцатки, собранный своей базой.
Модель оценки — `levels/EVAL.md`, детерминированный вариант (раздел
«Пакетная оценка» там же).

повторяет запись один в один: проигрыш весь в содержании групп.

Главный вывод сложности читается в двух строках: **оригинал берёт сложность

рождается из «а куда же это положить», а у нас — из «я такого слова не знаю».
Это же и объясняет, почему при почти равном D фан отличается вдвое.

## Три конкретные болезни ремейка

**1. Надписи-признаки вместо тем.** 33 группы из 192 названы так, что игрок их
не угадывает, а добирает по остатку: STRETCHY THINGS, THINKING ACTIONS,
DISSOLVING THINGS, WETNESS WORDS, SPINNING THINGS, PLUMBING WORDS, OFFICE
SKILLS, KINDS OF FOREST. В записи такая надпись ровно одна на двадцать уровней
(GEOGRAPHICAL OBJECTS). У оригинала темы называются словом: FRUITS, PETS, CAT,
COFFEE, DOCTOR, BREAD, CHESS.

**2. Пузырь, который не пузырь.** 90 токенов из 768 — многословные или длиннее
двенадцати символов: «harbor seal», «elephant seal», «answering phones», «note
taking», «rocky road». В записи таких 11. Уровень 5 наглядно:

| | оригинал REF005 | ремейк RMK005 |
|---|---|---|
| группы | PETS, CAT, BAKING, BEVERAGES, COFFEE, FLOWERS, INSECTS, DAIRY, POLYGONS, NUTS, ILLNESS | SEAL FAMILY, CARD GAMES, DESSERTS, ICE CREAM, COLONIAL AMERICA, FORENSICS WORDS, STATES OF MATTER, OFFICE SKILLS, HORSE BREEDS, DINNER PARTY, BLACKSMITH |
| слова | dog, fish, bird, cat / meow, purr, whiskers, scratch / cake, pie, cookie, bread | sea lion, harbor seal, elephant seal, walrus / hearts, poker, Solitaire, cribbage / colony, blacksmith, settler, musket |
| D / F | 10.0 / 8.0 | 6.5 / 3.5 |

**3. Ноль ага-моментов на двадцать уровней.** Генератор пересечения не ставит,
а отбраковывает: любое слово, которое тянет в соседнюю группу, отсеивается до
сборки. Оригинал на них держится — `orange` фрукт рядом с овощами, `carrot`
овощ оранжевого цвета, `cold` болезнь рядом с температурой, `bark` собачий лай
рядом с деревьями. По шкале это +1 к D и +0.5 к F за каждую, и уровень сложнее
туториала без единого ага-момента получает −0.5.

## Что это значит для задачи

Цель — двадцать уровней с F выше 6.53 и D не ниже 6.22. Порядок работ следует
прямо из таблицы вкладов: сначала надписи и читаемость пузырей (−1.45 и −0.15
лежат там), потом ловушки (−0.47 плюс снятие −0.20 «пресно»), и только потом
всё остальное. Первые два пункта — отбор контента, третий — новая механика
генератора.
