# Первая десятка: легче записи и из более расхожих слов

Ключи `TEN001..TEN010`. Задача пакета одна и проверяемая: быть **заметно легче**
первых десяти уровней записи оригинала и состоять из **более расхожих** слов.
Не «превзойти по оценке» — это делает `../first-lineup-20/` — а мягко ввести
в игру.

Кривая: 1.0 · 5.0 · 3.0 · 5.5 · 5.5 · 6.0 · 7.0 · 5.5 · 4.0 · 3.5.
Растёт с туториала до семёрки и мягко спадает. У записи на том же отрезке
1.0 · 6.0 · 4.5 · 6.5 · **10.0** · 7.5 · 8.5 · 7.0 · 5.5 · 7.0 — то есть
десятка автора выходит на десять баллов уже на пятом уровне.

Фан ниже записи на 0.45, и это прямое следствие задачи: у автора 16 ловушек
на десять уровней, здесь 4. Ловушка — главный источник и сложности, и «ага»;
убрать её и сохранить фан нельзя. Пакет сознательно меняет остроту на
проходимость.

## Профиль `first_ten`

Отдельный профиль, а не «first_lineup с послаблением»: двигать надо в разные
стороны сразу — пороги знакомости вверх, требования к ясности группы вверх,
сложность вниз.

| | first_lineup | first_ten |
|---|---|---|
| минимальная знакомость слова | 0.43 | **0.48** |
| средняя знакомость четвёрки | 0.52 | **0.60** |
| минимальная доступность | 0.55 | **0.58** |
| ясных якорей в группе | 3 из 4 | **4 из 4** |
| порог активации якоря | 0.60 | **0.62** |

Требование «якорем обязано быть каждое слово» — главное отличие. В первой
линейке группа имеет право на одно слово, которое подтверждает тему, но её не
называет; здесь тему видно по любому пузырю. Одна честная ловушка
(`common_secondary`) на группу остаётся: без неё пакет становится не лёгким,
а пустым.

Цена измерена: пул сжимается с 1079 четвёрок в 250 категориях до 430 в 117.
На десять уровней (95 групп) этого хватает с запасом; на двадцать — уже нет,
поэтому профиль называется `first_ten`, а не `easy`.

## Что здесь честно слабее

**Мета-связей 3.** Мета-пара требует, чтобы надпись правила была обычным
однословным существительным, и в суженном пуле таких пар почти не остаётся.
На десяти уровнях это заметно меньше, чем 25 у двадцатки.

**Абстрактные темы никуда не делись.** LEGAL DOCUMENTS, ACADEMIC DEGREES,
PERSONALITY TRAITS — слова расхожие, но представить их нельзя. Слой значений
отвечает на вопрос «вспомнит ли игрок значение», а не «можно ли его
вообразить»; признака предметности в базе нет.

## Как воспроизвести

```bash
cd tool/word_content_pipeline

.venv/bin/word-content generate-level-candidates --db database/content.sqlite \
    --limit 10 --categories 0 --seed 303 --key-prefix TEN \
    --profile first_ten --config data/content/cooldown_first_lineup.yaml \
    --obvious-until 2

.venv/bin/word-content assess-levels --db database/content.sqlite --origin generated
.venv/bin/word-content validate-meta  --db database/content.sqlite
.venv/bin/word-content eval-levels    --db database/content.sqlite --prefix TEN \
    --profile first_ten --output ../../levels/eval/TEN-pack.eval.json

.venv/bin/word-content export-level-pack --db database/content.sqlite --prefix TEN \
    --output ../../levels/packs/first-ten-easy/pack.json \
    --playable-dir ../../site/playable/levels
```

Seed 303 выбран замером, а не наугад: из десяти проверенных он единственный
даёт кривую без пика выше 7.0 при среднем 4.6. Соседние результаты для
сравнения — seed 909: 4.40 при пике 7.5; seed 101: 4.95 при пике 9.5.

## Как сыграть

Прототип читает уровень файлом:

```
site/playable/index.html?level=levels/ten1.json    … ten10.json
```

Проверено в браузере на локальном сервере: уровни 1, 7 и 10 грузятся без
ошибок в консоли, группа собирается перетаскиванием, счётчик считает.
