# Двадцать уровней по кривой оригинала, собранные нашей базой

Пакет отвечает на один вопрос: **может ли система собрать своим контентом то,
что мы разобрали по записи оригинала**. Не «похоже по духу», а по числам —
состав каждого уровня взят с записи того же номера.

Собирается шагом 18.5 полной пересборки базы (`scripts/rebuild_all.sh`), то есть
пакет в репозитории и база в репозитории всегда одного возраста. Те же две
команды по отдельности, если нужно пересобрать только пакет:

```bash
cd tool/word_content_pipeline
.venv/bin/word-content generate-level-candidates --db database/content.sqlite \
    --limit 20 --categories 0 --seed 101 --key-prefix RMK
.venv/bin/word-content export-level-pack --db database/content.sqlite \
    --prefix RMK --output ../../levels/packs/reference-remake-20/pack.json
```

Зерно фиксировано, состав берётся с записи — при той же базе результат тот же.
Числа ниже сняты 03.08 после пересборки базы; до неё в снимке не хватало
пятнадцати правил из патча по записи, и пакет собирался беднее.

`--categories 0` означает «состав по записи»: пять категорий на первом уровне,
двенадцать на седьмом, семь на пятнадцатом. Числа берутся не из головы, а из
`data/reference/video-levels-20.json` через `composition.py`.

## Что совпало

| | Оригинал | Пакет |
|---|---|---|
| уровней | 20 | 20 |
| категорий всего | 192 | **192** |
| категорий по уровням | 5, 8, 8, 10, 11, 11, 12, 12, 10, 8, 12, 12, 8, 10, 7, 9, 11, 11, 9, 8 | **то же, уровень в уровень** |
| мета-связей | 56 | **54** |
| уровней с мета | 17 из 20 | **17 из 20** |
| первая мета | уровень 3 | **уровень 3** |
| максимальная глубина мета | 2 | **2** |
| пузырей | 768 (в кадр попали 752: уровень 18 снят не целиком) | 768 |

Все двадцать уровней прошли автоматическую приёмку: `solver_valid`
(единственное решение у каждого), отрыв авторского разбиения +0.75…+0.85 при
пороге 0.06, мета-граф проходим, нарушений перезарядки нет.

Мета-механика получилась не «одна связь для галочки». На седьмом уровне пять
связей сразу: `TOY CHEST` собирается из результата `BALLS`, `SAUCES` — из
`BARBECUE`, `HOME DECOR` — из `LIGHTING`, `SCHOOL EVENTS` — из `SCIENCE FAIR`,
`BEACH DAY` — из `SWIMWEAR`. В записи оригинала так же устроен `measurements`
на седьмом и `healthy eating` на семнадцатом.

## Что не совпало

**Мета: 54 против 56.** Недобрали по одной связи на уровнях 7 и 20; на
остальных восемнадцати состав по мета-связям совпал с записью. Причина недобора
не в механике, а в контенте: мета-пара требует, чтобы надпись одного правила
была играбельным словом другого, и таких пар в базе 162 на 14 081 четвёрку. На
поздних уровнях свободные пары кончаются — перезарядка не даёт повторить уже
использованное правило.

**Ловушки: 7 честных на пакет против 29 в записи.** Это главный разрыв.
Оригинал строит интерес на пересечениях: `orange` — фрукт и цвет, `bark` —
собака и дерево. Наш генератор пересечения в основном **избегает**:
правила-конфликты отсеиваются до сборки, и уровень выходит чистым, с отрывом
авторского разбиения +0.8 там, где у оригинала было бы +0.2. Механика
спроектированной ловушки уже работает (`level_decoys`, `planned_decoys`,
оценка силы связи в solver'е) и дала ловушку на четырёх уровнях из двадцати —
4, 11, 18, 19. Довести её до плотности оригинала — следующая задача.

**Знакомость слов: 0.548 против 0.594 у записи.** Наши слова в среднем чуть
менее ходовые. Профиль качества по номеру уровня в генераторе есть
(`--profile auto`: знакомые слова на первых уровнях, знание предметной области
на поздних; полосы сняты с замера записи, где средняя знакомость падает с 0.691
на первом уровне до 0.52 на пятнадцатом). Но включать его в этом пакете
оказалось дороже, чем выгода:

| пул | четвёрок | правил | мета-пар доступно |
|---|---|---|---|
| без профиля | 14 081 | 1 262 | **162** |
| easy_accessible | 669 | 220 | **2** |
| accessible_fun | 1 818 | 468 | **13** |
| hard_knowledge | 4 916 | 847 | 50 |

Мета-пары сидят в трудной части базы: чтобы связь работала, имя правила должно
быть обычным словом (CAT, COFFEE, DOCTOR — как в оригинале), а у нас такие
правила чаще названы в два слова (CAT BREEDS, COFFEE DRINKS) и отсекаются
порогами лёгкого профиля. Замер на том же зерне: с `--profile auto` пакет даёт
25 мета-связей вместо 54 и мета остаётся в 10 уровнях вместо 17.
Выбрана фидельность композиции; закрывать разрыв нужно контентом — короткими
однословными надписями для бытовых тем, — а не порогами.

## Мелочи, которые видно глазами

- Два слова повторяются в пакете дважды, и оба — **в разных смыслах**: `ring`
  (звон в MUSIC SOUNDS на 6 уровне / кольцо в JEWELRY на 18) и `guest` (гость в
  BIRTHDAY THINGS на 3 / часть слова `guest house` в `___ HOUSE` на 11).
  Это не дефект, а фактура игры; перезарядка считается по паре слово-значение.
- Уровень 5: `CRAFTS` держит пузырь `candle making`, и `CANDLE MAKING` — сама
  группа того же уровня. Это мета-связь по замыслу, но два многословных пузыря
  рядом читаются тяжело. Такое ловит человек на приёмке.

## Как поиграть

Пакет лежит на сайте в блоке «06 Build Playable»: селектор «Уровень» → группа
**«Сдано · Ремейк двадцатки оригинала»**. Файл готовится из `pack.json` одной
командой и добавляется в список пакетов прототипа:

```bash
cd tool/level-tool
python3 scripts/pack_to_handoff.py ../../levels/packs/reference-remake-20/pack.json \
    --label "Ремейк двадцатки оригинала" > ../../site/playable/packs/remake20.handoff.json
# и один раз — имя файла первой строкой в site/playable/packs/index.json
```

Мета-пузырь прототип узнаёт сам: слово, равное имени другой категории уровня,
не спавнится на старте, а появляется, когда та категория собрана.

Лимит ходов у пакетов пайплайна не хранится: доска стала частью уровня позже,
чем собран этот пакет. Поэтому `pack_to_handoff.py` **досчитывает** лимит по той
же формуле, что и генератор, — иначе прототип играл бы с бесконечными ходами, а
это половина механики. Получается R1 — 23 хода при K 1.48, R7 — 51 при 1.41,
R20 — 35 при 1.44. Числа записи оригинала того же номера лежат рядом в
`composition`, но на доску прототипа здесь не переносятся.

## Что в файле

`pack.json` — двадцать уровней целиком: группы с надписями и правилами, слова с
их ролью (`lexical_word` или `category_output` с указанием группы-источника),
мета-связи, оценка сложности, отчёт solver'а и состав записи того же номера
рядом для сравнения. Формат — `bubble-level-pack/1.0`, он **не** совпадает со
старым `levels/SCHEMA.md`: в той схеме нет мета-механики, а без неё пакет
описать нечем.

Уровни живут в базе под ключами `RMK001..RMK020` — отдельный префикс, чтобы
дымовой прогон сборки (`L001..L005`) их не затирал.
