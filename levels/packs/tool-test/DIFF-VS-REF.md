# Тестовая группа T1-T10: сверка сложности с референсом

Источник: `game-pack-1-10.json` (выгрузка инструмента, `generator_version: gen-1.0`,
`seed: final-03`), забрана из Загрузок 31.07.2026. Конвертирована в формат
playable скриптом `tool/scripts/pack_to_playable.py` -> `site/playable/levels/t1..t10.json`,
в селекторе сайта отдельная группа «Тестовая группа».

Эталон для сверки: `reference-analysis.md` (покадровый разбор LVL1-20) и ответы
оригинала L1-199 (`reference/bwj-answers/bwj_levels.json`, 20/20 совпало с видео).

**Вывод: пакет НЕ соответствует уровням 1-10 референса. Это уровни поздней
палитры (~L150+ по контенту), выданные под номерами 1-10.** Ниже цифры.

## 2. Узнаваемость слов: мимо на целый порядок

`zipf` - логарифм частоты слова в языке (5 = «дом, красный», 3 = «шпатель», 2 = экзотика).

| | наш пакет | референс L1-10 |
|---|---:|---:|
| медиана zipf | **3.58** | **4.35** |
| доля слов zipf<3.0 (редкие) | **20%** | **5%** |
| доля многословных ответов | **14%** | **0%** |
| доля имён собственных | **18%** | **0%** |
| доля слов длиннее 9 букв | **16%** | **1%** |

Разница медиан 0.77 zipf = наши слова встречаются в языке примерно **в 6 раз реже**.
На L1-L3 у референса редких слов **ровно 0%**, у нас 19-21%.

Что реально лежит на поле T1 (это уровень ПЕРВЫЙ):
`steinbeck, verne, kipling, bronte, turquoise, magnolia, antigua, haiti,
grenada, splint, gauze, antiseptic, sandpaper, fasteners, french horn, satin`.

Что лежит на L1 референса:
`cow, horse, goat, pig / red, blue, green, yellow / car, bus, bicycle, truck /
north, south, east, west / monday, sunday, tuesday, friday`.

## 3. Простые «якорные» категории не взяты вообще

Референс на L1-10 держится на самых узнаваемых группах: `farm animals, colors,
vehicles, compass, days of the week, numbers, planets, shapes, body parts,
weather, jobs, meals, family, calendar, gems`.

В нашей базе `tool/data/categories.json` они ЕСТЬ и с высоким zipf:
`numbers` 5.97, `odd-numbers` 5.70, `calendar-units` 5.68, `months` 5.41,
`school-subjects` 5.33, `compass` 5.30, `time-units` 5.26, `colors` 5.15,
`family` 5.14, `americas` 5.08, `shapes` 4.97, `house-parts` 4.96,
`body-parts` 4.96, `continents` 4.92, `weekdays` 4.89, `pets` 4.85.

**Из 30 самых узнаваемых категорий базы пакет взял 2. Из 60 - взял 5.**

Причина видна по трассировке: из 145 уникальных категорий пакета только **22
есть в базе** по id (27 по имени), из 580 слов в базе только **149**. То есть
инструмент собирал контент мимо курированной базы - а значит мимо zipf-аннотации,
блок-листа и индекса пересечений. Ранжирования по узнаваемости в нём нет.

## 4. Досыпка: игрок видит слишком малую часть уровня

Поле вмещает 24 пузыря (как в референсе), но слов на уровне 48-72 против 20-48.

| LVL | видно на поле у нас | видно в референсе |
|----:|--------------------:|------------------:|
| 1  | 46% (24 из 52) | **100%** (все 20) |
| 5  | **33%** (24 из 72) | 55% |
| 9  | 35% (24 из 68) | 60% |

Референс на L1 кладёт весь уровень на поле сразу - потому и без лимита ходов.
У нас на L1 видно меньше половины: пар в поле зрения мало, ходы уходят в ожидание
досыпки. Это отдельный, невидимый в конфиге источник сложности.

## 5. Мета-цепи и «неразделимые пары» - жёстче референса

- Мета-пары (слово = имя другой категории уровня): у нас с L1 (2 шт.), в
  референсе первая на L3, до L7 их 1-2. У нас на L5 - **5 штук**.
- Глубина мета-цепи на T9 = **4** (`HOSPITAL THINGS <- EMERGENCY ROOM <-
  ILLNESSES <- DISEASES`) при `maxMetaDepth: 3` в конфиге - похоже на баг счётчика.
- Модификатор `chains` (цепь делит поле) стоит на T5 и T9. В референсе chains
  вводятся на **L20**. В нашем прототипе они не реализованы, поэтому в playable
  эти уровни идут без цепи (данные сохранены в `extensions.chains`).

Хуже другое: на одном уровне стоят категории, которые не разделяются словами -
ровно то, что записано как урок в `status.md` («неразделимые пары на один уровень
не ставить, решатель это ловит»):

| уровень | пара | почему ломается |
|---|---|---|
| T5 | CONSTELLATIONS + ZODIAC SIGNS | Leo, Aries, Scorpio, Capricorn - и знаки, и созвездия |
| T5 | SAUCES + CONDIMENTS | mustard/ketchup/mayo валидны в обеих (валидатор дал warn) |
| T9 | DISEASES + ILLNESSES | polio/anemia vs diabetes/flu - признака деления нет |
| T9 | EMERGENCY ROOM + HOSPITAL THINGS | то же самое ярусом выше |
| T10 | TOYS + TOY CHEST | doll/blocks/balls vs slinky/frisbee (валидатор дал warn) |
| T10 | OWLS + ARCTIC ANIMALS | snowy owl лежит в ARCTIC, а OWLS - целая категория |
| T4 | POULTRY + FARM + PLACES WITH ANIMALS | тройная вложенность одной темы |
| T6 | BIRDS + BIRDS OF PREY | + goose/seagull/canary вне пула базы |

Слепой решатель на этом пакете почти наверняка даст FAIL на T5, T9, T10 - но
прогонять его сейчас смысла нет: пакет надо пересобирать, а не чинить точечно.

## 6. Что править в генераторе

1. **Кривая категорий вместо коридора.** Для уровней 1-10 план должен быть
   `5-8-8-10-11-11-12-12-10-8`, а не `13..18`. Коридор [8,10] в конфиге был, но
   `categoryPlan` его перебил - план не проверяется на соответствие коридору.
2. **Порог узнаваемости, зависящий от номера уровня.** L1-3: только слова
   zipf>=4.0, ноль редких. L4-7: до 10% слов zipf 3.0-4.0. L8-10: до 20%.
   Сейчас `rarityRange: [9,13]` - это, судя по значениям, не zipf, а какая-то
   своя шкала; на выходе она не держит ничего.
3. **Форма слова.** Для L1-10: одно слово, до 9 букв, без имён собственных
   (в референсе на L1-10 их 0%). Многословные ответы оригинал вводит с L3,
   но дозированно; наша база сознательно однословная - надо не ломать это.
4. **L1 = туториал.** `move_limit: null`, все слова уровня на поле
   (`start_bubbles == 4*M`), мета-пар и модификаторов ноль.
5. **Досыпка как параметр сложности.** Держать видимую долю уровня не ниже
   ~50% до L10 (референс: 100% на L1, 50-69% дальше), то есть ограничивать M
   не только «сколько категорий», но и «сколько слов при поле 24».
6. **Ввод механик по расписанию референса**: мета-пары с L3 (1-2 шт., глубина 2),
   chunks с L10, chains с L20. Сейчас всё это выдаётся с L1-L5.
7. **Собирать контент из базы, а не в обход.** Трассировка id категорий и слов
   в `tool/data/categories.json` должна быть обязательной: без неё не работают
   ни zipf-порог, ни блок-лист, ни защита от неразделимых пар.
8. **Гейт на неразделимые пары.** Перед выдачей: для каждой пары категорий
   уровня проверять пересечение ПУЛОВ (не только выбранных 4 слов) - это уже
   умеет `tool/scripts/validate_level.py` (warn «незаявленная ловушка»),
   надо поднять до ошибки внутри генератора.
9. **Формула лимита.** Мелочь, но 5 уровней из 10 расходятся с
   `ceil(3*M*K)` на 1 ход - округление считается не по формуле схемы.
