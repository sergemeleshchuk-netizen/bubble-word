TASK: propose candidate words for one category of an American English word association puzzle.

LANGUAGE: American English.
AUDIENCE: an average American adult casual player (no specialist knowledge).

CATEGORY
  category_key:   $category_key
  label:          $label
  rule:           $rule
  relation_type:  $relation_type
  theme:          $theme

WORDS ALREADY IN THIS CATEGORY (do not repeat them):
$existing_words

AVAILABLE CATEGORY KEYS (the ONLY keys allowed in possible_other_category_keys):
$available_category_keys

RULES
1. Propose exactly $count candidate words that satisfy the category rule literally.
2. Use words a casual American player recognizes instantly.
3. Prefer single words. Multi-word entries only when the phrase is the natural form; flag them "multiword".
4. Do not include rare, archaic, technical, jargon or strongly regional terms.
5. Do not include a word only because it is metaphorically or loosely associated with the label.
6. Never stretch beyond the formal rule, even if the label alone would allow it.
7. State the intended sense explicitly: sense_key is a short snake_case id (for example apple_fruit),
   sense_definition is one short dictionary-style sentence. Both are required together.
8. relation_type must be the category relation_type unless a different one is clearly more accurate.
9. fit_score = how correct the membership is under the rule (0..1).
   obviousness_score = how quickly an average player sees it (0..1).
   These are independent: a correct but non-obvious member gets high fit and low obviousness.
10. possible_other_category_keys may only contain keys from the list above; use [] when unsure.
11. Add risk_flags whenever the entry is debatable. Allowed flags:
    obscure, regional, proper_noun, multiword, culturally_specific,
    weak_relation, highly_ambiguous, sensitive, possible_duplicate.
12. It is better to return fewer solid candidates than to pad the list with weak ones.

OUTPUT: raw JSON only, no markdown, exactly this shape:
{
  "category_key": "$category_key",
  "candidates": [
    {
      "word": "apple",
      "part_of_speech": "noun",
      "is_proper_noun": false,
      "sense_key": "apple_fruit",
      "sense_definition": "The edible fruit of an apple tree",
      "relation_type": "is_a",
      "reason": "An apple is a common edible fruit",
      "fit_score": 0.99,
      "obviousness_score": 1.0,
      "possible_other_category_keys": ["pie_ingredients", "things_with_seeds"],
      "risk_flags": []
    }
  ]
}
