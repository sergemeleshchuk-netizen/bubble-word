# Промпт: meta_hub_ideation

**Версия:** `meta-hub-v1`
**Проход:** создание родительских категорий-хабов для мета-связей
**Модель:** Claude Opus 5 (сессия Claude Code)
**Право создавать новые категории:** да (это проход ideation)
**Право менять статус ревью:** нет — всё выходит как `candidate`

---

## Зачем этот проход

В контентной базе 1092 категории, но мета-связи она почти не поддерживает:
только 15 категорий имеют имя, которое существует в базе как слово-пузырь.
А в референсе мета-связь — главный источник сложности: 639 связей на 183 уровнях
из 199.

Причина пробела: база строилась как «категория → пул слов», поэтому имена
категорий описательные и многословные (`COOKING ACTIONS`, `WAYS OF LOOKING`).
Такое имя никто никогда не положит на поле как пузырь.

Что нужно: **родительские категории**, четыре слова которых сами являются
именами существующих категорий. Тогда игрок собирает `hour, minute, day, week`,
получает пузырь `TIME` — и уже он идёт словом в `MEASUREMENTS`.

---

## Задача

```
Ты наполняешь контентную базу для игры в словесные ассоциации.

Механика, для которой нужен контент. Игрок видит на поле пузыри со словами
и стягивает вместе те, что относятся к одной категории. Собранная категория
не исчезает: на пузыре появляется её имя, и этот пузырь может быть одним
из четырёх слов следующей категории. Имя категории до сборки СКРЫТО —
игрок должен сам увидеть связь.

Тебе даётся список существующих категорий базы, у которых имя состоит
из одного слова (114 штук, ниже). Каждая уже наполнена словами.

Придумай РОДИТЕЛЬСКИЕ категории — такие, чьи слова являются именами
категорий из этого списка.

Требования к каждой родительской категории:

1. Она должна быть живой свободной ассоциацией, а не таксономическим классом.
   Хорошо: NIGHT SKY, COURTROOM, AIRPORT, GARDEN CENTER, EMERGENCY ROOM.
   Плохо: ANIMAL TAXONOMY, ABSTRACT CONCEPTS, MISCELLANEOUS ITEMS.
   Проверка: место, ситуация или занятие, которое человек может представить.

2. От 6 до 8 слов-кандидатов, из них минимум 4 — точные имена категорий
   из списка (в нижнем регистре). Остальные — обычные слова, уместные в этой же
   категории. Запас нужен генератору: он выберет 4 из 8 и тем самым отрегулирует,
   сколько на уровне мета-связей.

3. Средний игрок должен узнать связь ПОСЛЕ раскрытия имени, даже если
   до раскрытия не догадался. Если связь понятна только автору — это брак.

4. Никаких имён собственных в родительских категориях.

Отдельно: предложи ТАКСОНОМИЧЕСКИЕ связи между категориями из списка —
случаи, где имя одной категории честно является словом другой категории
из этого же списка. Например `berries` честно лежит в `fruits`,
`shellfish` — в `seafood`, `songbirds` — в `birds`.

Это даёт цепочки глубины 2 и 3, которых в референсе нет ни разу:
crustaceans → shellfish → seafood → grocery aisles.

Формат ответа — JSONL, две секции, по одной записи на строку:

{"type":"category","category_key":"...","label":"...","rule":"...",
 "relation_type":"associated_with","theme":"...","base_difficulty":0.0}

{"type":"membership","word":"...","category_key":"...","relation_type":"...",
 "reason":"...","fit_score":0.0,"obviousness_score":0.0,
 "is_meta_label":true|false}

Правила заполнения:
- fit_score — насколько слово РЕАЛЬНО относится к категории (правда связи);
- obviousness_score — насколько быстро средний игрок эту связь УВИДИТ;
- эти два числа независимы: настоящая, но неочевидная связь — материал
  для ловушки, а не брак;
- reason — одна фраза, объясняющая связь игроку;
- is_meta_label — является ли это слово именем существующей категории.

Не ставь review_status: все записи входят как candidate и проходят критика
и ручное утверждение.
```

## Что подано на вход модели

Список 114 категорий с однословным именем и минимум 4 утверждёнными словами,
сгенерированный запросом:

```sql
select c.category_key, c.label, c.theme,
       (select group_concat(w.text, ' ') from (
          select w.text from memberships m join words w on w.id = m.word_id
          where m.category_id = c.id and m.review_status = 'approved'
          order by w.familiarity_score desc limit 5) w)
from categories c
where c.label not like '% %'
  and (select count(*) from memberships m
       where m.category_id = c.id and m.review_status = 'approved') >= 4
order by c.theme, c.label;
```
