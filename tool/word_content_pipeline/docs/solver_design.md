# Solver полного уровня

## Что он доказывает

Уровень — это N скрытых категорий по четыре слова. Игрок видит только слова.
Уровень корректен, только если весь набор раскладывается на четвёрки **ровно
одним способом**. Иначе игрок соберёт ответ, правильный с его точки зрения,
а игра его не примет — худший вид сложности из возможных.

## Чего не доказывала прежняя проверка

Функция называлась `quartet_is_unique`, и это читалось как «уровень с этой
четвёркой однозначен». Проверялось другое: не лежит ли данная четвёрка целиком
в чужом пуле. Проверка одной группы.

Неоднозначность рождается на стыке групп, и хватает одного общего слова:

```text
FLOWERS: rose, tulip, lily, daisy      COLOURS: red, blue, green, violet
FLOWERS: violet, tulip, lily, daisy    COLOURS: red, blue, green, rose
```

Обе четвёрки локально безупречны. Уровень из них имеет два ответа. Поэтому
функция переименована в `quartet_locally_unique`, колонка `quartets.solver_state`
стала `local_check` со значениями `local_unique` / `local_ambiguous`, а
уникальность уровня живёт только в `level_instances.solution_count`.

## Алгоритм

Exact cover перебором с отсечением, `src/word_content/level_solver.py`.

1. **Вход** — список токенов. Токен это пузырь: слово + значение + надпись.
2. **Валидация входа.** Число токенов кратно четырём; нет двух одинаковых
   надписей; у многозначного слова указано значение. Иначе `invalid_input`.
3. **Интерпретации.** Для каждой категории собираются все четвёрки токенов
   уровня, которые она принимает. Учитываются значение, режим обращения со
   словом (`sense_mode`) и структура категории (пары, последовательности).
4. **Покрытие.** Рекурсивный поиск разбиений всего набора на непересекающиеся
   четвёрки. Ветвление по токену с наименьшим числом вариантов: если у токена
   нет ни одной группы, ветка мертва сразу. Категория входит в уровень один раз.
5. **Остановка.** Поиск прекращается на втором решении: чтобы отклонить
   уровень, второго достаточно.
6. **Итог.** `unique` только при `solution_count == 1`.

### Почему интерпретации ищутся шире, чем генерация

Генератор берёт слова статусов `approved` и `alternative`. Solver рассматривает
ещё и `hard_only`. Игрок не знает наших статусов: если он физически способен
собрать альтернативную группу, уровень неоднозначен независимо от того, каким
статусом мы пометили связь у себя. Отклонённые связи и `semantic_status =
incorrect` не рассматриваются — их в игре нет.

## Исходы

| Исход | Что означает | Уровень принят |
|---|---|---|
| `unique` | ровно одно разбиение | да |
| `ambiguous` | найдено второе разбиение | нет |
| `unsolvable` | не раскладывается ни одним способом | нет |
| `invalid_input` | дубли, некратность четырём, значение не указано | нет |
| `timeout` | не уложился в бюджет времени | нет |
| `error` | внутренняя ошибка | нет |

Таймаут — это «не знаю», а не «уникально». Найденное до таймаута ничего не
доказывает: непросмотренная ветка может содержать второе разбиение. Проверка
времени срабатывает начиная с самого первого узла, поэтому нулевой бюджет
отсекает сразу, а не после пятисот узлов.

## Что сохраняется о каждом запуске

`level_solver_runs`: версия solver'а, хеш входа, параметры, исход, число
решений, альтернативное разбиение (для отклонённых), причина, длительность,
время проверки. Без этого «уровень проверен» — утверждение без доказательства.

Хеш входа считается от отсортированного набора токенов и параметров: порядок
слов в уровне на него не влияет, изменение любого слова — влияет.

## Regression-набор

`tests/test_level_solver.py`, 16 тестов. Каждый — уровень, который обязан
пройти или обязан быть отклонён.

| Тест | Что ловит |
|---|---|
| `test_unique_level_passes` | базовый случай не сломан |
| `test_two_fully_alternative_groups_rejected` | два полных разбиения одного набора |
| `test_one_word_swap_ambiguity_rejected` | rose/violet: обмен одним словом |
| `test_multi_word_swap_ambiguity_rejected` | обмен несколькими словами |
| `test_duplicate_token_is_invalid_input` | два одинаковых пузыря |
| `test_unresolved_sense_is_invalid_input` | многозначное слово без значения |
| `test_resolved_sense_passes` | то же слово со значением решается |
| `test_timeout_is_not_unique` | таймаут не считается успехом |
| `test_rejected_membership_removes_ambiguity` | отклонённая связь не участвует |
| `test_hard_only_membership_still_creates_ambiguity` | hard_only участвует |
| `test_intended_groups_cover_full_token_set` | покрытие без остатка |
| `test_input_hash_is_stable_and_sensitive` | детерминизм отпечатка |

## Стоимость

Уровень из 20–32 токенов, база из 1276 категорий: обратный индекс
слово → категории сводит перебор к единицам кандидатов на токен. Пять уровней
на реальной базе решаются за время меньше миллисекунды каждый (замер в
`generate-level-candidates`). Бюджет по умолчанию — 5 секунд, он не расходуется.
