# Инструкции для AI-агентов

Ты работаешь в проекте тестового задания: AI-инструмент генерации уровней
для словесного пазла Bubble Associations. Контекст проекта: `CLAUDE.md`,
подробные правила: `rules.md`, текущее состояние: `status.md`.

## Как работать

- Перед действием сверься с `status.md`: что уже сделано и что сейчас в работе.
- Изменил что-то существенное: обнови `status.md` и сделай коммит с понятным сообщением.
- Команды запускай с абсолютными путями; многошаговую логику клади в скрипт-файл,
  а не в длинную shell-строку.
- Секреты (API-ключи) не записывай в файлы репозитория. Для локальной разработки
  используй `.env` (он в `.gitignore`).
- Тяжёлые бинарники (видео, PSD) складывай в `reference/`, они не коммитятся.

## Критерии готовности

- Фича «готова» только после проверки в реальном браузере.
- Сгенерированный уровень «валиден» только после прохождения слепого решателя
  (независимая AI-проверка без подсказок) и программных проверок счётчиков.
