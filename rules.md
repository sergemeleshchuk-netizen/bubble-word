# Правила проекта

## Суть задания (кратко)

Собрать рабочий веб-инструмент, который:
1. Генерирует уровни: AI-наборы «категории + слова» с настраиваемой сложностью.
2. Проверяет решаемость: у каждого слова однозначный «дом», количество пузырей
   совпадает с конфигурацией, нет тупиков.
3. Оценивает сложность: числовая оценка + объяснение, из чего она складывается.
4. Экспортирует уровни в JSON, пригодный для загрузки в игру.

Сдаём: ссылку на рабочий инструмент, репозиторий, 10 уровней с оценками,
описание AI-воркфлоу (какие инструменты, ключевые промпты, что руками).

## Принципы работы

- Делаем ровно то, что описано в задании; идеи сверх скоупа сначала предлагаем словами.
- Спорные дизайн-решения обсуждаем до кода, а не после.
- Ограничения и риски называем сразу, в первом ответе.
- Факты с высокой ценой ошибки (что лежит на хосте, что в репозитории) проверяем
  инструментом (curl, ls, git log), а не по памяти.

## Версионирование

История версий живёт в git: каждый смысловой шаг = отдельный коммит.
Отдельные файлы v1/v2 не плодим, откат и сравнение делаем средствами git.

## Модель сложности уровня (черновик, уточняем по ходу)

Оценка складывается из факторов, каждый объясняется в отчёте инструмента:
- очевидность связи «слово - категория» (собака-животные просто, меркурий сложно);
- слова-ловушки: правдоподобно подходят к двум категориям, но однозначно к одной;
- семантическая близость категорий между собой;
- количество категорий и слов на уровне;
- редкость/частотность слов.

## Проверка решаемости (три слоя)

1. Программные проверки: количество пузырей сходится, нет повторов слов.
2. Слепой решатель: независимый AI-запрос получает только слова и категории
   (без ответов) и раскладывает сам; расхождение с задумкой = уровень бракуется.
   Генератор сам себя не проверяет.
3. Отчёт проверки виден в интерфейсе инструмента.

## Публикация

- Сайт-отчёт: `npx surge ./site serge-mel.surge.sh`
- Инструмент: статическая страница на отдельном surge-домене + серверный прокси
  для ключа AI (бесплатный Cloudflare Workers или Vercel). Ключ живёт только
  в настройках прокси, в репозиторий не попадает.

## Проверка качества

- Победные/рабочие сценарии инструмента проверяем в реальном браузере до слова «готово».
- Каждый из 10 сдаваемых уровней проходит слепой решатель и просмотр глазами.
