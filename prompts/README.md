# История промптинга

Промпты, которые двигали проект, с разбором: что в них сработало и чего
не хватило. Хронологически:

| Файл | Что это |
|---|---|
| `word-db-bootstrap.md` | Создание базы слов и pipeline с нуля (этап 1). Спецификация со схемой БД, правилами нормализации, продуктовыми правилами и списком тестов. |
| `category-depth.md` | Глубина категорий по кривой сложности: чтобы поздние уровни не собирались из тем первой десятки. |
| `word-db-audit-gpt-pro.md` | Внешний аудит той же базы через ChatGPT Pro + промпт-задание на исправления. Материалы аудита — в `word-db-audit-pack/`. |

Пара `word-db-bootstrap` → `word-db-audit-gpt-pro` читается вместе: видно,
какие дыры в качестве данных остаются даже после подробной спецификации
и что их находит только независимая проверка чужой моделью.
