# Промпт: blind_solver

**Версия:** `blind-solver-v1`
**Проход:** независимая семантическая проверка уровня
**Требование:** отдельная сессия, **без** доступа к репозиторию, базе и ответам

---

## Почему два режима, а не один

В целевой игре имя категории **скрыто до сборки** — это наблюдалось на всех
20 разобранных уровнях. Решатель, которому дали имена категорий, решает
принципиально более лёгкую задачу, чем игрок. Поэтому режимов два, и у них
разные цели (`docs/SPEC_AUDIT.md` §7).

## Режим A — membership_audit

Проверяет **качество контента**: однозначно ли слово относится к своей категории.

```
Тебе дан список имён категорий и перемешанный список слов.
Разложи все слова по категориям: в каждой ровно 4 слова, каждое слово
используется один раз.

Категории:
<имена категорий уровня, перемешанные>

Слова:
<все слова уровня, перемешанные детерминированным seed>

Для каждой категории верни:
  - четыре слова,
  - уверенность 1..5,
  - список слов, по которым сомневался, и почему.

Не угадывай ради заполнения: если считаешь, что слово подходит двум
категориям, скажи об этом прямо.

Ответ строго JSON:
{ "assignment": [ {"category": "...", "words": ["..."], "confidence": 1,
                   "doubts": [{"word": "...", "why": "...", "alternative": "..."}]} ] }
```

## Режим B — gameplay_grouping

Проверяет **реальную сложность**: имён категорий нет вообще.

```
Тебе дан перемешанный список слов. Они разбиваются на группы ровно по 4 слова.
Имён групп ты не знаешь — их надо придумать самому.

Слова:
<все слова уровня, перемешанные>

Верни группы, для каждой:
  - четыре слова,
  - как ты назвал бы эту группу,
  - уверенность 1..5,
  - слова, из-за которых колебался, и между какими группами.

Если считаешь, что возможна другая разбивка тех же слов, опиши её.

Ответ строго JSON:
{ "groups": [ {"words": ["..."], "label": "...", "confidence": 1,
               "doubts": [{"word": "...", "between": ["...", "..."]}] } ],
  "alternative_partition_possible": false,
  "notes": "..." }
```

Для мета-уровня режим B прогоняется в два шага: сначала по обычным словам,
затем повторно — после того, как имена собранных категорий добавлены в пул.

## Как читать результат

| Что произошло | Что это значит | Что делать |
|---|---|---|
| PASS, все заявленные ловушки вызвали сомнение | ловушки кусают, но честно | принять |
| PASS, ловушки не вызвали сомнений | ловушки слабые, вес F3 завышен | чинить **формулу** |
| FAIL | в уровне скрытая двусмысленность | чинить **уровень** |
| Слово потеряно или подменено | баг пайплайна, не уровня | чинить код |

`unplanned_hesitations` — сомнения ВНЕ заявленных ловушек. Только они идут
в F7; сомнения по заявленным ловушкам идут в F3, иначе один и тот же эффект
считался бы дважды.

## Статус в этой сдаче

**Прогоны не выполнены.** Слепой прогон требует отдельной сессии без доступа
к репозиторию: сессия, в которой собирался пакет, видела ответы и не может
считаться слепой. Поэтому в оценках финальных уровней поле
«незапланированная спорность» равно нулю **как неизмеренное**, а не как
подтверждённо нулевое — так и написано в разбивке каждого уровня.

Вход для прогона готовится командой:

```bash
node scripts/solver_input.ts --level 205 --mode B
```
