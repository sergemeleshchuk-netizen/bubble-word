# Генератор уровней для word-association паззла

Инструмент, который собирает блоки уровней для игры **Bubble Associations: Word
Game** (`com.vgames.bubbleword`): AI обогащает контентную базу, детерминированный
алгоритм собирает из неё уровни, валидатор доказывает структурную корректность,
независимый решатель проверяет смысл, человек оценивает интересность.

> **Демо:** ссылка появится здесь после деплоя (`web/`, статика на surge.sh).
> Демо-режим работает без API-ключа: вся генерация считается в браузере
> на замороженном снимке базы.

---

## Главная идея в одном абзаце

AI генерирует **контент**, а не уровни. Один прогон обогащает базу на тысячи
связей «слово ↔ категория», из которых собираются десятки тысяч уровней. Уровни
собирает детерминированный код: тот же конфиг + тот же seed + тот же снимок базы
дают тот же `level_spec_hash`. Если поставить модель в горячий путь — на каждую
сборку уровня — кривой сложности нельзя управлять, а брак нельзя воспроизвести.

Цепочка, которую проходит каждый уровень:

```
AI-кандидат → проверка схемы → adversarial-ревью → утверждение человеком
  → детерминированный отбор → структурная валидация → единственность решения
  → слепой семантический аудит → ручная игра
```

## Воспроизвести проверки

```bash
python3 scripts/audit_reference.py        # аудит данных → docs/DATA_AUDIT.md
```

**Оговорка про референсные данные.** `reference-levels.json` — выгрузка ответов
чужой игры (Bubble Word Jam). Она используется офлайн как источник кривой
сложности и в публичный репозиторий не выкладывается. В репозитории лежат
производные агрегаты (`reference-metrics.csv`, `reference-vocabulary.csv`)
и замороженный результат аудита (`data/audit.json`). Чтобы пересчитать аудит
с нуля, файл нужно положить в `data/reference-derived/` самостоятельно.

## Ключевые факты, на которых стоит дизайн

Всё Measured — посчитано по 199 уровням референса, воспроизводится аудитом:

- **ровно 4 слова в категории** — 2244 из 2244, ни одного исключения;
- **ноль повторов слова внутри уровня** — на всех 199 уровнях;
- **639 мета-связей** на 183 уровнях: имя одной категории лежит словом в другой;
  граф — ациклический **лес** (в среднем 2.12 независимых компонент), не дерево;
- **глубина 3 не встречается ни разу** — неиспользованный рычаг сложности;
- **инвариант открытой двери**: в каждом из 199 уровней есть минимум одна категория
  быстрой победы — без мета-слов, все 4 слова частотные;
- **две фазы кривой**: до L120 растёт мета-плотность (29% → 42%), после L120
  растёт объём (35 → 52 пузыря), а мета падает до 13%;
- **пила**: 74 перехода из 198 идут вниз — сложность не монотонна.

И два факта из наблюдений за целевой игрой, которых нет в выгрузке:

- **лимит ходов** = `ceil((3 × категорий + склейки) × K)`, K от 1.6 до 1.25;
- **поле держит 20–24 пузыря** одновременно, остальные досыпаются волнами —
  значит `start_bubbles` это размер уровня, а не размер экрана.
